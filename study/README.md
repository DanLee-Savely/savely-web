# 인터넷의 원리

- 클라이언트
  - DNS 질의를 통해서 도메인 주소(가비아)를 공인 IP 주소로 변환한다.(국내 상표권: 마크인포)
    - 도메인 주소: naver.com
    - IP 주소: 127.0.0.1
  - 보내고 싶은 데이터(예: 아이디, 비밀번호)를 준비합니다.
  - 위에서 만든 데이터에 통신 프로토콜 헤더를 추가합니다.
    - TCP: 택배 안전 배송 프로토콜(중간에 데이터가 유실되면 재전송)
    - UDP: 택배 초스피드 배송 프로토콜(중간에 데이터가 일부 유실되도 무시)
  - 위에서 만든 데이터에 보내는 사람, 받는 사람 IP 주소를 추가합니다.
    - 보내는 사람 IP 주소: 사설 IP 주소
    - 받는 사람 IP 주소: 공인 IP 주소
  - 위에서 만든 데이터에 보내는 컴퓨터, 받는 컴퓨터 Mac 주소를 추가합니다.
  - 위에서 만든 데이터를 전기 신호로 변환해서 케이블을 통해 외부로 전송한다.

- 서버
  - 받은 전기신호를 데이터로 복원한다.
  - 헤더에 적혀있는 받는 사람의 Mac 주소가 자신의 Mac 주소와 같은지 확인한다.
  - 헤더에 적혀있는 받는 사람의 IP 주소가 자신의 IP 주소와 같은지 확인한다.
  - 헤더에 적혀있는 통신 프로토콜이
    - TCP: 검증 절차를 거쳐서 빠진 데이터가 있다면 재전송을 요청하고 데이터를 순서대로 받아서 조립한다.
    - UDP: 검증 절차를 거치지 않는다.
  - 서버에서 데이터를 확인한다.
  - 동일한 방법으로 서버에서 다시 클라이언트로 응답 데이터를 보낸다.

# 서버와 데이터베이스

- 데이터베이스
  - 서버에서 데이터를 저장하고 관리하는데 사용하는 프로그램
  - 고도로 발달된 엑셀입니다.
  - 종류
    - 관계형 데이터베이스
      - SQL: 관계형 데이터베이스를 사용하기 위한 쿼리 언어
      - 예: PostgreSQL(오픈소스), MySQL(오픈소스)
    - 비관계형 데이터베이스
      - 예: MongoDB

- 클라우드 서비스
  - 서버 또는 데이터베이스와 같이 서비스를 운영하는데 필요한 프로그램들을 작동시킬 컴퓨터를 원격으로 대여하는 서비스
  - 예: AWS, GCP, NCP
  - DevOps(SRE): 대여한 컴퓨터를 트래픽에 따라 자동으로 조절하는 등 인프라 자체를 코드로 제어해서 비용을 절감한다.(여러분은 이 부분을 고민할 필요가 없다.)

# JS 런타임

- 런타임은 프로그램이(을) 실행되는(시키는) 환경을 의미합니다.
- JS 런타임은 JS 코드를 실행시킬 수 있는 엔진(V8)을 포함하고 있습니다.
- JS 런타임은 두 종류가 있습니다.
  - 브라우저
    - 브라우저에서 실행시킬 HTML(웹 페이지를 구성하는 문서)
    - 브라우저에서 실행시킬 CSS(웹 페이지를 꾸미는 문서)
    - 브라우저에서 실행시킬 JS(웹 페이지를 조작하는 코드)
  - Node.js
    - 서버에서 실행시킬 JS(웹 페이지를 조작하는 것 이외의 모든 일)

# Node와 NPM

- Node: 서버에서 실행시킬 JS(웹 페이지를 조작하는 것 이외의 모든 일)
- NPM: JS 오픈소스 패키지 매니저(다운로드, 기록) 프로그램
  - 예시: prettier를 사용해봅시다.
  - 다운로드 및 설치: npm install prettier
    - 다운로드 위치: node_modules 폴더
    - 설치 히스토리 기록: package.json, package-lock.json
  - 사용방법: package.json의 scripts에 커맨드를 등록 후 npm run [커맨드] 실행
  - node_modules는 깃허브에 업로드하지 않습니다.
    - 용량이 매우 큼
    - npm install 명령어를 통해서 package.json에 있는 패키지 설치 히스토리를 보고 node_modules를 복구할 수 있다.
    - 따라서 굳이 업로드할 이유가 없다.
