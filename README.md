# 세이블리 소개 사이트 (savely-web)

## 검수 기록

| 섹션 | 시안과 달랐던 점 | 고친 방법 |
|---|---|---|
| 00 GNB | 모바일 메뉴 시트 아래에 시안에 없는 1px 테두리가 보임 (shadcn Sheet 기본값) | `data-[side=top]:border-b-0`으로 덮어씀 |
| 00 GNB | 메뉴 · 신청 창 배경 막이 shadcn 기본(검정 10% + 흐림)이라 시안(`#08140F` 45%, 흐림 없음)과 다름 | `sheet.tsx` 배경 막을 `bg-sv-backdrop` 토큰으로 교체 |
| 01 히어로 | 화면을 30px만 끌었다 놓아도 「탭」으로 처리돼 다음 장으로 넘어감 | 손을 뗄 때 판단을 `CarouselCursor.release()`로 모음: 10px 미만 이동만 탭, 가로 40px 이상만 스와이프 |
| 01 히어로 | 1024px에서 문구 칸이 496px로 줄어 56px 제목이 4줄로 꺾임 | 가로 배치를 xl(1280)부터 시작. 1024~1279는 제목 2줄 + 휴대폰 세로 배치 |
| 02 공감 | 마지막 문장이 시안보다 12px 위에 붙음 (Figma의 12px 빈 칸을 빠뜨림) | 말풍선과 마지막 문장 사이를 36px(12 + 12 + 12)로 맞춤 |
| 03 문제 | 「→ ↓ ↺」 기호를 Pretendard가 굵은 아이콘 모양으로 그려 시안(가는 화살표)과 다름. GNB 모바일 메뉴의 「→」도 같음 | lucide `ArrowRight` · `ArrowDown` · `RotateCw`(선 굵기 1.75)로 교체 |
| 03 문제 | 모바일 섹션이 8px 더 큼 (카드 강조용 투명 테두리 1px가 카드마다 높이를 2px씩 늘림) | 강조 테두리를 크기에 영향 없는 안쪽 선(`ring-inset`)으로 바꿈 |
| 04 금융 문해력 | 모바일 시안에는 「ⓘ」가 없어 탭으로 툴팁을 여는 자리가 보이지 않음 | PC처럼 모바일에도 「ⓘ」를 표시(00-decisions H). 터치는 hover를 쓰지 않고 탭으로만 열고 닫음. 높이 750/1105, 툴팁 위치 +175로 시안과 같음 |
| 05 해결 | 모바일 카드의 앱 화면이 시안보다 위쪽이 잘려 보임 (원본 비율 302×656으로 넣음. Figma는 302×671 칸에 꽉 채워 자름) | 이미지를 302×671 칸에 `object-cover`로 채운 뒤 Figma 세로 위치(-81 / -67 / -242)로 자름 |
| 06 습관 보상 | 차이 없음 (높이 579 / 876, 순환 간격 0.9 · 0.9 · 1.4 · 0.9초 측정). 「→ ↺」 기호만 03과 같은 이유로 lucide 아이콘 사용 | — |
