- 모든 커맨드는 프로그램 이름이고, 커맨드를 입력하고 엔터를 치는 것은 해당 프로그램을 실행하는 것(마우스로 더블 클릭)과 같다.
  - 나 지금 어디에 있지?: pwd
  - 지금 여기에 뭐가 있지?: ls -l(자세히) -a(숨김 폴더 보기)
  - 터미널 초기화: clear
  - 나 어떤 폴더로 이동할래
    - cd [경로]
      - .(현재 폴더)
      - ..(상위 폴더)
      - /(루트 폴더)
      - ~(내 폴더)
  - 폴더를 만들어보자: mkdir [경로]
  - 파일을 만들어보자: touch [파일이름]
  - 폴더를 지워보자: rm -r [경로]
  - 파일을 지워보자: rm [파일이름]
  - 파일의 내용을 출력해보자: cat [파일명]
  - 파일의 앞부문만 출력해보자: head -n 3 [파일명]
  - 파일의 뒷부문만 출력해보자: tail -n 3 [파일명]
