# 운영체제

- 사용자 프로그램이 컴퓨터의 하드웨어에 접근하는 것을 추상화하는 프로그램

- 사용자 프로그램의 예시
  - 터미널: 사용자가 명령어를 통해서 운영체제와 소통하는 것을 도와주는 프로그램
    - shell: 터미널에 입력된 명령어를 운영체제가 사용할 수 있도록 해석해주는 프로그램
      - 윈도우: Power Shell(PS)
      - 맥: zsh
      - 우분투: bash
  - 다양한 프로그램들(크롬 브라우저, ZOOM, ...)

- GUI, CLI
  - GUI: 그래픽 유저 인터페이스
    - 윈도우, 맥, 안드로이드, iOS와 같은 대중 친화적인 운영체제는 기본적으로 GUI를 지원합니다.
  - CLI: 커맨드 라인 인터페이스(윈도우, 맥, 안드로이드, iOS를 제외한 나머지 전부)
    - 일반적으로 서버에서 주로 사용됩니다.
