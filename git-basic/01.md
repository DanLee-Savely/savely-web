# 깃

## 버전 관리 시스템(깃)

- 프로젝트 폴더를 버전별로 저장할 수 있게 해주는 프로그램

## 깃 설치

- 공식 홈페이지에서 설치

## 깃 사용자 설정

- git config --list
- git config --global user.name "깃허브에서사용하는사용자이름"
- git config --global user.email "깃허브회원가입에서사용한이메일"

## 깃 사용하기

1. 프로젝트 폴더를 깃으로 관리하기 시작한다.

- git init
- .git 폴더가 생성된다(숨김 폴더)

2. 깃으로 관리하는 프로젝트 폴더는 아래의 3단계로 구분됩니다.

- 워킹 디렉토리: 상품 목록
- 스테이징 에어리어: 장바구니
- 로컬 리포지토리: 구매 내역

3. 현재 프로젝트 폴더의 상태를 파악해보자

- git status: 커맨드를 쓰지 않고 에디터의 UI로 파악하면 됩니다.
  - 스테이징 에어리어(장바구니)에 추가된 상품과 안된 상품을 구분해서 보여준다.

4. 워킹 디텍토리에서 저장할 파일들을 선택해서 스테이징 에어리어에 추가합니다.

- git add [파일]: 커맨드를 쓰지 않고 에디터의 UI로 파악하면 됩니다.

5. 스테이징 에어리어의 상태를 그대로 저장합니다.

- git commit -m "메세지": 커맨드를 쓰지 않고 에디터의 UI로 파악하면 됩니다.

6. 저장된 기록 목록을 확인해보자.

- git log: 커맨드를 쓰지 않고 에디터의 UI로 파악하면 됩니다.

7. 깃허브에 업로드해보자.

- 깃허브에 회원 가입을 한다.
- 나의 깃허브 계정에서 원격 저장소를 하나 생성한다.
- 원격 저장소 등록: git remote add [별명] [원격저장소주소]
- 원격 저장소에 업로드: git push [별명] [브랜치이름]
  - 만약 로그인이 안되어 있다면 로그인
  - 윈도우: 쉽게 된다.
  - 맥: 비밀번호를 쓸 때 토큰을 입력해야 한다.
