# 문구 규칙 (화면 문구 · README를 만질 때 적용)

- 화면 문구의 원본은 `docs/spec/content.json`이다. 임의로 바꾸지 않는다. 바꿔야 하면 사용자에게 먼저 묻는다.
- 문구는 컴포넌트에 직접 쓰지 않고 `src/content/home.content.ts`에서 가져온다.
- **포인트 명칭:** 소개 사이트에서는 「세이블리 포인트」만 쓴다. `SVX`는 쓰지 않는다(앱 · 로그인 후 화면 전용).
- **금지 표현:** 가상자산, 토큰, 코인, 블록체인, 출금, 현금처럼, 정액 보장, 수익, 투자
- **마켓:** 오픈 날짜를 쓰지 않는다. 「마켓이 열리면」으로만 쓴다. 마켓은 만 19세 미만이 이용할 수 없으므로 「누구나」처럼 이와 어긋나는 표현을 쓰지 않는다.
- **숫자 비노출:** 보상 적립량(하루 · 주간)과 월 적립 한도를 쓰지 않는다.
- **회원 등급:** 「무료회원」 금지. 결제하지 않은 회원은 「일반」, 결제한 회원은 멤버십 이름
- **다른 회사 로고 금지:** 스토어 배지 등은 텍스트로만 쓴다.
- **전화번호:** 화면에 쓰지 않는다. 필요하면 「대표번호」로만 쓴다.
- **회사명:** 「세이블리」(00-decisions C5). 「주식회사 세이브댓머니」는 쓰지 않는다.
- **실제 사용자 데이터 금지:** 앱 화면 이미지는 `docs/assets/app/`의 더미 데이터 캡처만 쓴다.
- 커밋 전 점검:
```bash
grep -rnE "가상자산|토큰|코인|블록체인|출금|현금처럼|정액 보장|수익|투자|SVX|무료회원" src/content src/components src/app && echo "금지 표현 발견" || echo "OK"
```
