참고
- 21~27번은 「대화로 기록하기」 **v1 시안**이다. 명세 80 v2(2026-11-25)에서 바뀌어 **21번(홈 + 떠 있는 버튼)만 유효**하고 22~27번은 쓰지 않는다.
- **30~56번이 v2 시안**이다(2026-11-25). 동작 · 문구는 앱이 정본이고, 시안은 패널 크기와 PC 화면에 맞춘 배치다. 30~44번은 결정 K1~K15에 맞춰 다시 내보냈고, 45~56번은 새로 그렸다.
- v2 예시 데이터: 10월 기록 81건(기존 78건에 상환 2 · 저축 1 추가, 「생활용품」 지출은 카테고리 없는 기록으로 바꿈). 지출 합계 1,086,400원은 그대로다. 「기타」는 13,500원이라 홈의 「많이 쓴 곳」(상위 3개)에는 나오지 않고 리포트에만 보인다.
- 49 · 52 · 53번은 내용이 길어 높이가 1000이다.
- 사진 칸의 컵 그림은 자리표시다. 실제 화면에서는 올린 사진을 보여 준다.
- 금액 · 날짜 등 숫자는 예시 데이터다(10월 기록 78건 · 지출 1,086,400원 기준으로 화면끼리 맞춤).
- 정산 · 연속 정산 · 완벽한 주 · 보상(SVX)은 로그인 이후라 시안에 없다(M17). 2026-11-04 대시보드 시안(「APP · …」 프레임)은 참고하지 않는다.
- 모바일 화면은 만들지 않는다(M16).
