## 0. 읽는 법 · 우선순위
- **기존 부분**(섹션 머리말, 03 흐름, 05 단계 전환, 06 고리, 07 토글, 문구, 간격)은 지금 저장소의 코드 · `docs/spec`이 기준이다. `preview.html`의 기존 부분은 재현본이라 1~2px 차이가 있을 수 있다.
- **새 요소**(아래 1~5장)는 `preview.html`의 동작 · 타이밍 · 배치가 기준이다. 수치는 이 문서에 옮겨 두었다.
- `preview.html`에만 있는 것은 구현하지 않는다: 왼쪽 아래 「A안 샘플 · 효과 끄기」 안내 칩, `?capture=` 촬영 모드, 가짜 커서, 「생략」 띠(02 · 04 · 11).
- 프로젝트 규칙(토큰만 사용 · 텍스트 스타일 · 객체 지향 구조 · reduced-motion · 계획 → 승인 → 실행)은 그대로 따른다. 샘플 코드의 16진수 색 · 임의 글자 크기는 아래 8장의 토큰 · 스타일로 바꿔 구현한다.

## 1. 사용자 확정 사항 (00-decisions에 기록할 것)
1. 히어로 A안: 기록 카드 → 정산 도장 → 연속 정산 일수. 날아다니는 돼지 아이콘은 **넣지 않는다**(검토 후 제외).
2. 03 · 05 · 06 · 07에도 같은 요소를 넣는다. 02 · 04 · 11은 바꾸지 않는다.
3. 03의 「1,825,000원」 카운트는 **금액 영역이 화면에 30% 이상 보이면 바로** 시작한다(흐름 애니메이션을 기다리지 않는다).
4. 05 모바일(카드 목록)에는 새 요소를 넣지 않는다.
5. 새 색은 토큰으로 등록한다(8장).
6. 아래 2장의 새 문구를 승인했다.

## 3. 히어로 (preview.html 상단, hero.mp4)
- **배경 빛:** 캔버스 2개 층(휴대폰 뒤).
  - 초록: accent 7.5%, 반지름 430, 휴대폰 중심 근처에서 느리게 이동.
  - 금빛: `#ead9a8` 38%, 반지름 360, 휴대폰 오른쪽 위.
  - 마우스 주변: accent 7%, 반지름 200. 히어로가 화면 밖이면 멈춘다.
- **달력 카드 (휴대폰 왼쪽 아래, 앞쪽):**
  - 크기 244 폭, 휴대폰 중심 기준 (-252, +232). 모바일은 (-128, +236)에 0.64배.
  - 머리 `{n}일 연속 정산 중` + 불꽃 아이콘. 요일 줄, 날짜 원 24px.
  - 도장 = accent 원 + 흰 숫자, 오늘 = accent 테두리, 아직 = 회색 숫자.
  - 시작 상태는 1~11일 도장, 12일이 오늘.
- **기록 카드 2칸:** 휴대폰 중심 기준 (-192, -238), (+186, +96)에서 번갈아 나온다.
  - 0.25초에 첫 카드가 나오고, 이후 1.3초마다 다음 카드가 나온다.
  - 한 장은 2.3초 보인다(처음 12%는 아래에서 14px 올라오며 나타나고, 마지막 14%는 8px 올라가며 사라진다).
  - 카드가 나오고 0.55초 뒤 오늘 날짜에 도장이 찍히고(0.42초 easeOutBack 확대 + 0.7초 퍼지는 테두리) n이 1 오른다.
  - 25일까지 차면 1.6초 멈춘 뒤 달력이 0.5초 흐려졌다가 11일 상태로 다시 0.5초 나타난다(반복).
- **마우스:**
  - 휴대폰이 커서 쪽으로 rotateY 최대 4.5° · rotateX 최대 3.5° 기운다(perspective 1400).
  - 카드들은 커서 반대쪽으로 움직인다(가로 26px · 세로 18px × 깊이: 기록 카드 1.1, 달력 0.8).
  - 휴대폰은 늘 위아래 4px 떠 있다(sin 0.9).
- **동작 줄이기:** 움직임 없음. 14일까지 도장, 기록 카드 1장 고정.

## 4. 03 문제 (s03-problem.mp4)
- 기존 흐름(0.9 · 0.9 · 0.9 · 0.9 · 2.5초, 1번 재생)은 그대로 둔다.
- **사라지는 기록 카드 (PC만):**
  - 위치: 「잊고」 열 중심(가로 37.5%) 아래, 단계 설명 바로 아래 · 돌아오는 선 안쪽. 3장이 한 줄로 놓인다.
  - 흐름 시작 기준 0.95 + 0.25k초에 나타난다(0.25초).
  - 0.8초 뒤 0.55초 동안 흐려지며 사라진다(blur 6px, 위로 12px).
- **금액 카운트 (별도 시계, 금액 영역이 30% 이상 보일 때부터):**
  - 「하루 5,000원」 0.2~0.7초, 「한 달 150,000원」 0.45~0.95초, 「1년」 0.7~2.6초 동안 accent 색으로 강조된다.
  - 금액은 0.85초에 나타나고, 1.0~2.6초 동안 0 → 1,825,000원으로 오른다(easeOutCubic, 도중에는 천 원 단위로 반올림).
  - 끝나면 0.35초 동안 1.035배로 커졌다 돌아온다. 색은 기존 risk, 글꼴은 기존 Amount/Display.
- **접근성 · 동작 줄이기:** 금액 요소의 `aria-label`은 항상 최종값. 동작 줄이기면 처음부터 최종값을 보여주고 카드는 숨긴다.

## 5. 05 해결 (s05-solution.mp4) — PC 단계 전환에만
- 기존 3.5초 자동 전환 · 클릭 시 정지는 그대로 둔다.
- **카드 위치:** 단계 목록 아래 빈 곳. 오른쪽 끝 = 휴대폰 왼쪽 + 32px, 세로 중심 = (목록 아래 끝 + 휴대폰 아래 끝) / 2 + 6.
- **카드 전환:** 단계가 바뀌면 0.15초 뒤 0.35초 동안 나타난다(아래에서 12px). 자동 전환 중에는 다음 단계 0.3초 전에 사라진다.
- **01 쓴 돈을 직접 적어요:** 기록 카드 `카페` + 금액.
  - 0.55초부터 0.8초 동안 `0원 → 4원 → 48원 → 480원 → 4,800원`으로 바뀐다(입력 중에는 accent 커서 막대).
  - 1.5초에 체크 원(accent)이 튀어나온다.
- **02 하루를 돌아보고 마감해요:** 한 주 카드(20~26일).
  - 20~25일은 도장, 26일은 오늘이다.
  - 1.0초에 26일 도장이 찍히고 `25일 → 26일 연속 정산 중`이 된다.
- **03 쌓인 기록에서 내 습관을 발견해요:** 리포트 아이콘 + `10월 가장 많이 쓴 곳은 식비예요`. 0.9초에 「식비」 아래 accent-tint-2 강조가 생긴다.
- **마우스:** 휴대폰이 rotateY 최대 4° · rotateX 최대 3° 기울고, 위아래 3px 떠 있다.

## 6. 06 보상 (s06-reward.mp4)
- 기존 고리 순환(0.9 · 0.9 · 1.4 · 0.9초)은 그대로 둔다.
- **고리:** 「포인트 받고」가 켜질 때 `+P`가 칩의 +P 자리에서 0.9초 동안 22px 떠오르며 사라진다.
- **카드 「마감할 때마다」:** 날짜 원 3칸(어제 도장 · 오늘 · 내일).
  - 고리가 한 바퀴 돌 때마다 하루씩 넘어간다(0.45초 동안 왼쪽으로 한 칸 이동).
  - 「마감하고」에서 오늘에 도장이 찍히고, 「포인트 받고」에서 그 도장 위로 `+P`가 떠오른다.
  - 날짜는 25일부터 시작하고, 31일 다음은 1일이다.
- **카드 「꾸준할수록 더」:** 월~일(19~25일) 7칸 + ★ 1칸.
  - 0.3초부터 0.42초마다 한 칸씩 도장이 찍힌다.
  - 3.25초에 ★(accent 원)이 튀어나오고, 3.45초에 ★ 위로 `+P`가 떠오른다.
  - 5.0~5.3초에 흐려지고, 5.3~5.6초에 빈 상태로 나타나 다시 시작한다(5.6초 주기, 섹션이 보일 때만).
- 「쓸 수 있는 포인트」 카드는 그대로 둔다.
- **동작 줄이기:** 「포인트 받고」 고정. 카드 1은 오늘 도장, 카드 2는 7칸 + ★.

## 7. 07 습관이 되면 (s07-habit.mp4)
- 기존 토글(선택 배경 0.35초, 카드 페이드)은 그대로 둔다.
- **달력 카드:**
  - PC는 섹션 콘텐츠 오른쪽 위(머리말과 같은 높이)에 300px 폭으로 둔다. 날짜 원은 26px, 줄 간격은 4이며, 아래 카드 줄과 겹치지 않아야 한다.
  - 모바일은 토글 아래 · 카드 위에 전체 폭(최대 340)으로 둔다.
- **점검이 빠진 한 달:** 도장 없음(날짜는 더 연한 회색), `정산 0/31일`.
- **세이블리와 함께한 한 달:** 누른 뒤 0.3초부터 1일 → 31일 순서로 35ms마다 도장이 찍히고(확대 + 테두리), n이 31까지 오른다.
- **다시 「점검이 빠진 한 달」:** 31일 → 1일 순서로 12ms마다 지워진다.
- 날짜 위에 마우스를 올리면 1.15배 커진다.
- **동작 줄이기:** 누르면 바로 바뀐다.
