# 핵심 결정 요약

> README에서 옮겨 온 문서다(2026-11-27). 본문의 파일 경로는 저장소 루트 기준이다. 돌아가기: [README](../../README.md)

처음 보는 사람을 위한 요약이다. 결정 전체와 이유는 `docs/spec/00-decisions.md`(괄호 안 번호), 검수 상세는 [검수 기록](review-log.md)과 `docs/spec/71-mvp-qa.md`에 있다.

| 영역 | 결정 | 이유 |
|---|---|---|
| 핵심 행동 | 앱 다운로드 대신 「출시 알림 신청」 하나만 두고, 이메일을 실제로 저장(D1)한다. 보관은 최대 1년 (B1 · A7 · B3 · B4) | 출시 전이라 스토어 링크가 없고, 저장하지 않으면서 「보내 드릴게요」라고 하면 사실과 달라짐 |
| 메시지 | 포인트는 「습관을 돕는 보상」으로만 설명하고 적립 수치는 보여 주지 않는다. 금융 문해력 수치는 원문과 대조해 인과 표현 없이 쓴다 (A4 · A5 · A9 · A10) | 돈벌이로 오해하거나 사실과 다른 문장을 막기 위해 |
| 디자인 | 라이트(화이트 · 그린) 시안 고정, 기록 카드 → 정산 도장 흐름의 A안 인터랙션 (D1 · D13) | 「돈(기록) · 습관(정산)」을 페이지 전체에서 같은 모양으로 보여 주기 위해 |
| 배포 | Cloudflare Workers 한 곳(`/home*` · `/app*`)에만 배포. Vercel은 쓰지 않음 (F3 · F8 · B6 · M12) | 보유 도메인 하나에서 소개 사이트와 체험판을 같은 프로젝트로 이어 가기 위해 |
| 보안 | 출시 알림 API는 다른 출처 · JSON 아닌 요청 · 큰 본문을 거부하고 IPv6 /64 단위로 요청을 제한한다. iframe 삽입 금지 헤더 (B6) | 보안 점검(2026-10-31)에서 나온 익명 쓰기 남용 여지를 작은 수정으로 줄임 |
| 체험판 저장소 | 기록은 D1 · 사진은 R2. 출시 알림과 **다른 데이터베이스**, 브라우저는 저장소에 직접 닿지 않음 (M8 · M14) | 누구나 쓰고 지우는 체험 데이터를 실제 이메일과 섞지 않기 위해 |
| 체험판 공개 | 로그인 없이 모두가 같은 데이터를 쓰므로 안내 띠 · 검색 제외(noindex) · 쓰기 요청 제한(1분 10회)을 함께 둔다. 사진은 위치 정보를 지운 뒤 올린다 (M12 · M15) | 실서비스 도메인에 공개 쓰기가 열리기 때문 |
| 체험판 범위 | 기록 CRUD + 홈 · 달력 · 리포트(기록만 읽어 계산). 정산 · 보상 · AI 리포트 · 예산 · 멤버십은 로그인 이후로 미룸. 모바일 화면은 앱이 맡음 (M1 · M17 · M18 · M16) | 「직접 적는다」를 검증하는 데 필요한 것만, 숫자의 주인이 없는 기능은 빼기 위해 |
| 대화로 기록하기 | 규칙 기반 파서가 먼저 읽고, **읽지 못한 부분만** OpenAI로 보낸다. 초안은 카드일 뿐이고 사용자가 확인해야 저장된다. 이유 · 기분은 AI가 추정하지 않는다 (80-A6 · 80 §1-2) | 모바일 앱과 같은 동작이 기준이고, OpenAI가 멈춰도 기록은 정리돼야 하며, 「직접 적는다」를 AI가 대신하면 안 되기 때문 |
| 대화로 기록하기 — 개인정보 · 비용 | 문장과 응답을 저장 · 로깅하지 않는다. 키는 서버에서만 쓴다. 문장 보내기 1분 20회 · OpenAI 호출 1분 6회 · 하루 300회, OpenAI 프로젝트 지출 한도 $5 (K17 · K18 · 80 §7 · §8) | 공개 체험판이라 누구나 문장을 보낼 수 있어서 |
| 기록 종류 | 지출 · 수입에 상환 · 저축을 더하고 카테고리 41종. 카테고리는 선택 사항 (80-A9 · K7) | 앱과 같게. 금액만 먼저 적고 나중에 채울 수 있어야 한다 |
| 체험판 규칙 | 금액 1원 ~ 1조 원 미만, 미래 날짜 금지(「오늘」은 한국 날짜), 삭제는 실제 삭제, 금액 · 막대 · 비율은 지출만 (M6 · M9 · M7 · M19) | 앱 서버와 같은 규칙 · 체험 편의 · 단순함 |

**검수 결과 한눈에:** 소개 사이트는 섹션별로 시안과 비교해 차이를 고쳤다(1440 · 1280 · 1024 · 768 · 390 · 360에서 가로 스크롤 · 콘솔 오류 · 깨진 링크 0, iOS 실기기 확인). 체험판은 QA 51개(Q1~Q51 — 2026-11-26에 Q1~Q30을 다시 돌리고 기록 종류 4가지 · 대화로 기록하기 14개, 패널 밖의 입구 · 소개 사이트 새 구역 7개를 더함)를 로컬 Worker 환경에서 모두 통과했고, 점검 중 찾은 버그(삭제 확인 창이 저절로 닫힘 · 두 번 저장 · 없는 기록이 HTTP 200 · 없는 날짜에서 멈춤 · `/app?…` 522)를 고쳤다.
