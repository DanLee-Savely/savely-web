# 00 · 결정 기록 (Decision Log)

기획·디자인 대화에서 확정한 결정과 그 이유를 모은 문서다. 구현 중 판단이 필요하면 이 문서가 기준이다.
여기 없는 판단이 필요하면 임의로 정하지 말고 사용자에게 묻는다.

## A. 페이지 흐름과 메시지

| # | 결정 | 이유 |
|---|---|---|
| A1 | HOME 흐름: 히어로 → 공감 → 문제 → 금융 문해력 중요성 → 해결(세이블리) → 습관 보상 → 습관이 되면 → 출시 알림 신청 → 하단 | 「공감 → 왜 문제인가 → 그래서 무엇이 중요한가 → 세이블리가 해결책 → 왜 꾸준히 하게 되는가 → 기대효과 → 행동」으로 이어지게 함 |
| A2 | 히어로 제목은 「오늘의 기록이 습관이 되고, 그 습관이 인생을 바꿉니다」 | 사용자 확정 문구 |

| A6 | 「상황별 시작」과 「나에게 맞는 멤버십」은 HOME에서 빼고 멤버십 페이지로 옮김 | HOME 흐름 단순화. 멤버십 페이지는 미션 5 범위 밖 |
| A7 | 히어로의 「패밀리 멤버십 알아보기」 버튼 삭제 | CTA를 하나로 집중 |

## E. 문구 규칙 (요약 — 전체는 `.claude/rules/copy-wording.md`)

- 소개 사이트의 포인트 명칭은 「세이블리 포인트」만 쓴다. `SVX`는 쓰지 않는다.
- 금지 표현: 가상자산, 토큰, 코인, 블록체인, 출금, 현금처럼, 정액 보장, 수익, 투자
- 마켓 오픈 날짜는 쓰지 않는다. 「마켓이 열리면」으로만 쓴다.
- 「무료회원」은 쓰지 않는다. 결제하지 않은 회원은 「일반」으로 쓴다.

## H. 구현 판단 (프로토타입에 없던 부분 — 사용자 확인 권장)
- 공감 말풍선 · 문제 흐름: 화면 진입 시 **한 번 재생 후 멈춤** (프로토타입은 Figma 한계로 반복 재생)
- 보상 고리: 화면에 보이는 동안 **반복 유지** (습관의 반복을 보여주는 의도)
- 해결 스텝: 사용자가 단계를 클릭하면 자동 전환을 멈춤
- 신청 창: 「전송 중」 상태와 오류 문구 추가 (시안에 없음, 문구는 content.json 초안)
- 메타 제목 · 설명, 이미지 대체 텍스트 문구 (시안에 없음, content.json 초안)
- 금융 수치 툴팁: 모바일에도 라벨 옆 「ⓘ」를 표시해 탭할 곳을 알림 (모바일 시안에는 없음)

1. 개인정보 보호책임자 표기: 성명 또는 「세이블리 운영 담당」 + `contact@savelyglobal.com`

2. 보관 기간 — 제안안: 「출시 알림 발송 후 지체 없이 파기, 최대 신청일로부터 1년, 취소 요청 시 즉시 파기」
3. 하단 회사명: 「주식회사 세이브댓머니」 / 「세이블리」 (법인 설립 전이면 「세이블리」)

4. 타깃 사용자 문구 확정 (CLAUDE.md §1 초안)
5. 금융 문해력 수치의 한국은행·금융감독원 원문 보도자료 대조 (현재는 언론 보도 3건으로만 확인)
