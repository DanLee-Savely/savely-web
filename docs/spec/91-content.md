## 1. 왜 하는가

「가계부」 · 「AI 가계부」 · 「수기 가계부」 · 「앱테크」처럼 질문을 검색하는 사람에게 보이는 것은 소개 페이지가 아니라 그 질문에 답하는 글이다. 글마다 끝에서 세이블리 소개(/home)와 출시 알림 신청으로 이어지게 하고, 어느 글이 신청으로 이어졌는지 GA4로 잰다(90 §2).

## 3. 글 규칙

1. **사실만.** 세이블리 기능은 지금 실제로 되는 것만 쓴다. 앱은 출시 전이므로 「출시 예정」, 웹 체험판은 「PC 웹 체험판」이라고 정확히 쓴다. 준비 중인 기능은 「준비 중」으로 표시한다.
2. **통계 · 연구 인용은 출처가 있을 때만**, 출처 링크와 함께. 출처 없는 숫자("10명 중 8명이…")는 쓰지 않는다.
3. **문구 규칙 그대로:** 수익 · 현금처럼 · 출금 · 정액 보장 · 투자 · 가상자산 · 토큰 · 코인 · 블록체인 · SVX · 무료회원 금지. 포인트는 「세이블리 포인트」, 쓰임은 「마켓이 열리면」 조건과 함께. 보상 금액 · 마켓 날짜는 쓰지 않는다.
4. **다른 서비스 이름 · 로고를 쓰지 않는다.** 「자동 연동 가계부」처럼 방식으로만 말한다.
5. **두 곳에 같은 글을 그대로 복사하지 않는다.** 같은 주제를 사이트용 · 블로그용으로 각각 다듬는다(도입 · 순서 · 말투를 다르게).
6. **검색어는 제목 · 첫 문단 · 소제목 한 곳에 자연스럽게.** 억지로 반복하지 않는다(90 §1).
7. **실제 소비 내역 · 개인정보를 예시로 쓰지 않는다.** 예시 문장은 소개 페이지 · 체험판에 이미 쓰는 것(「점심 9천원, 커피 4500원」 등) 위주로.
8. **이미지:** PC 웹 체험판 실제 화면 캡처(대표가 직접) 또는 디자인 시안. 시안을 쓰면 「화면 예시」라고 밝힌다.

## 4. 사이트 가이드 페이지 (Claude Code 구현)

1. **주소:** `/home/guide` (목록), `/home/guide/<slug>` (글). Worker 라우트 `/home*` 안이라 라우트 추가 없음.
2. **원고 위치:** `src/content/guide/<slug>.md`, 맨 위 머리말:
   ```
   ---
   title: 가계부가 매번 작심삼일로 끝난다면 — 꾸준히 쓰는 6가지 방법
   description: (검색 결과 설명문, 한두 문장)
   slug: gagyebu-habit
   status: draft        # draft | published
   publishedAt: 2026-12-01
   updatedAt: 2026-12-01
   ---
   ```
   `published`만 목록 · 사이트맵 · 검색에 나온다. `draft`는 주소로도 열리지 않는다(404).
3. **렌더링:** 빌드할 때 정적으로 만든다(`generateStaticParams`). Workers에는 실행 중 파일 읽기가 없으므로 실행 중 `fs`를 쓰지 않는다. 마크다운 변환 방식은 Claude Code가 고르되, 새 의존성을 넣으면 이유를 보고한다.
4. **글 화면:** 제목(H1) · 날짜 · 본문 · 글 끝 안내 상자. 모바일도 지원한다(/app과 다름). 디자인 토큰 · 글꼴은 소개 사이트 그대로.
5. **글 끝 안내 상자:** 세이블리 한 줄 소개 + 「출시 알림 신청」 버튼(기존 `WaitlistButton`, `source: "guide"` 추가) + PC에서만 「웹에서 체험하기」 링크(`/app?chat=1`). 상자 문구는 초안을 만들어 대표 승인 후 반영.
6. **측정:** 버튼은 기존 이벤트를 그대로 쓴다 — `waitlist_open` · `generate_lead`(`source=guide`), `demo_click`(`placement=guide`). 매개변수 `guide_slug`를 함께 보낸다(맞춤 측정기준 추가 등록 필요 — 대표 GA4 작업).
   - `WAITLIST_SOURCES`에 `guide`를 추가한다. D1 `waitlist.source`에도 그대로 저장된다(방침 2번의 「신청한 위치」 범위 안).
7. **구조화 데이터:** 글마다 `Article` JSON-LD (headline, datePublished, dateModified, author · publisher = Organization 세이블리).
8. **사이트맵 · canonical:** `published` 글을 사이트맵에 자동 추가, 각 글은 자기 주소를 canonical로.
9. **소개 사이트에서 들어가는 길:** GNB 또는 푸터에 가이드 링크. 이름은 「가계부 가이드」를 제안 — **대표 승인 필요.**
10. **사이트 안 링크에는 UTM을 붙이지 않는다** (붙이면 방문 경로가 덮여 측정이 틀어짐).

## 5. 네이버 블로그

1. **개설 (대표, 2026-11-26 완료):** 세이블리 명의 아이디로 개설 — `https://blog.naver.com/savelyglobal`. 첫 글(1번 주제) 게시 2026-11-26: `https://blog.naver.com/savelyglobal/224493415957`

## 6. 매주 절차
