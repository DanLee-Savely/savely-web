## 참고: MCP 없이 미리 추출해 둔 자료 (2026-10-28)
- Figma Plugin API로 추출했다. MCP 호출 횟수에 포함되지 않는다.
- `docs/figma/ui-home-pc-light.txt`, `ui-home-mobile-light.txt`: UI 시안 구조(크기 · 간격 · 토큰 · 문구)

- `docs/figma/tokens.json`: 색 · 간격 · 모서리 변수, 텍스트 스타일
