프로토타입 · 소개 (/) · 라이트 (화이트 · 그린)
· 프로토타입 보는 법 — 오른쪽 위 ▶(프레젠테이션) → 흐름 ‘소개 · PC · 라이트’ 또는 ‘소개 · 모바일 · 라이트’ 선택
· 출시 알림 신청: 상단 메뉴 · 히어로 · 마지막 CTA · 오른쪽 아래 떠 있는 버튼 → 신청 창 (이메일 칸 클릭 → 입력됨 → 알림 신청하기 → 완료 → 확인으로 닫기, 바깥 클릭으로도 닫힘)
· 상단 메뉴: 스크롤해도 고정 · 반투명 배경 / ‘소개’ 클릭 → 공감 섹션으로 이동 / 로고 클릭 → 맨 위로
· 히어로 휴대폰: 좌우 화살표 · 화면 탭 · 아래 점으로 앱 화면 5개 전환 (홈 → 기록 작성 → 달력 → 하루 상세 → AI 리포트, 옆으로 밀리는 전환 · 마지막 다음은 첫 화면)
· 실제 사이트 구현 시: 모바일은 좌우 스와이프도 추가 (Figma는 방향 구분 스와이프가 없어 탭 · 화살표로 대체)
· 공감: 말풍선이 ‘입력 중…’ 표시 후 하나씩 나타남 (반복 재생)
· 문제: 쓰고 → 잊고 → 놀라고 → 반복하고 순서로 강조 후 ‘매달 반복’ 띠 강조 (반복 재생)
· 금융 문해력: 숫자에 마우스를 올리면 지표 설명 · 출처 표시
· 해결: 왼쪽 단계 클릭 또는 3.5초마다 자동으로 오른쪽 휴대폰 화면 전환
· 습관 보상: 적고 → 마감하고 → 포인트 받고 → 내일 또 적고 순환 강조
· 습관이 되면: 상단 토글로 ‘점검이 빠진 한 달 ↔ 세이블리와 함께한 한 달’ 전환
· 모바일: ≡ 메뉴 → 아래에서 올라오는 메뉴 창(소개 · 출시 알림 신청) / 신청 창은 바텀시트
· Figma 한계: 실제 사이트에서는 애니메이션이 ‘해당 섹션이 화면에 들어올 때’ 시작되도록 구현 (프로토타입은 화면 진입 감지가 없어 반복 재생으로 대체)
· 모바일 범위: 문제 흐름 · 해결 스텝 · 금융 수치 애니메이션은 PC에만 적용 (모바일은 공감 · 습관 보상 · 전후 토글 · 메뉴 · 신청 시트)
· 라이트 버전 휴대폰 화면: 앱 라이트 모드 캡처 (이름 · 금액 · 결제수단 · 기록 내용은 더미 데이터로 교체, 2026.10.26)
· 다크(블랙 · 골드) 버전: 페이지 ‘프로토타입 · 소개 (/)’ — 구조 · 문구 · 인터랙션은 동일, 색 모드만 다름
